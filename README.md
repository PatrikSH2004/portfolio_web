# Portfolio Website - HA(it) Student CBS

A professional portfolio website for a HA(it) (Business Administration and Information Technology) student at Copenhagen Business School, designed for student job applications.

## Features

- **Professional Design**: Clean, modern layout with CBS-inspired color scheme
- **Responsive**: Fully responsive design that works on mobile, tablet, and desktop
- **Sections**:
  - Hero section with clear value proposition
  - About section highlighting background and goals
  - Education section showcasing HA(it) program details
  - Skills section covering technical, business, and soft skills
  - Projects section demonstrating practical experience
  - Contact section with multiple contact methods

## How to Use

1. Open `index.html` in a web browser to view the portfolio
2. Customize the content in `index.html`:
   - Replace `YYYY` with your expected graduation year
   - Update email to `your-name@student.cbs.dk` with your actual name
   - Update LinkedIn URL to your actual profile username
   - Add your actual projects and experiences
   - Modify skills based on your expertise
3. Customize colors in `styles.css` if desired (see CSS variables in `:root`)
